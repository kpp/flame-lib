# Flame implementation plan

- 🎻 Cell Type Language: first prototype implemented; see the [CTL specification and examples](../cells/ctl.md). Byte-oriented `.ctl` schemas use Rust-like syntax, earlier-field array lengths, `U8`/`U16`/`U32`/`U64` little-endian integers, canonical unsigned LEB128 as `V128`, and `^` Cell references. The compiler generates Rust Cell codecs; TL-B linear inversion (`~`) is excluded.
- Root-last graph transport implemented: see [the format and APIs](cells.md#root-last-graph-transport). One rooted DAG in children-first order, deduplicated Cells, backward `V128` reference indexes, and the final Cell as root. Hash preimages remain independent; availability and typed snapshots are ordinary Cell hierarchies with explicit pruning. The flat bag commitment and root-ID prefix are removed.
- Transaction CTL layout implemented: [flamevm/tx.ctl](../flamevm/tx.ctl). Tx has one body reference, inline 64-byte signature (zero means absent), and U16-length R1CS proof. TxBody has the header, program graph container (executable Cell and lookup snapshot), and a canonical mask-one pruned TxLog; VM checks the computed hash(0) and depth(0). Body ID is TxID, Tx root ID is WitnessID; both prover and verifier bind the original program graph, even after `exec`.
- Implemented `pushcell` (0xa6) and `exec` (0xa7). All frames execute raw Cell payloads with independent consuming byte/ref cursors, no program length prefix or Snake decoder. `exec` replaces the current code Cell, resets local cursors/labels, and preserves frame identity, stack, gas and rollback escrow. The builder packs straight-line code into instruction-aligned `pushcell exec` continuations; oversized instructions and automatic splitting of labeled programs are rejected.
- Native Contract input implemented: `input` consumes the raw Contract root Cell supplied by `pushcell`, claims its factual CellID, and decodes authenticated public paths before restoring private payload openings. It no longer accepts a 32-byte ID payload, Slice or Builder. `CellValue::contract(contract)` is fallible and constructs the actual root; host programs use `.push_cell(CellValue::contract(contract)?)` and native Cell verification/transport.
- Direct Cell-based Taproot opening implemented: `contract inner_key program_cell gas args… k open` authenticates hash(0), without native branch indexes or Trie lookup, and executes the supplied factual graph in an isolated frame. `runslice` (0xac) snapshots unread current-program bytes/refs after its own instruction; bytecode dispatch uses `loadref` and same-frame `exec`. Explicit pruning remains visible; pruned execution targets fail. Synchronous success/failure returns unused gas and preserves consumed-work charges; failures restore the original Contract and explicit arguments.
- Review graph-aware script-size admission policy. The retained `script()` byte view and script-byte limits now cover root bytecode only; transport-byte and gas limits still bound the whole supplied/executed graph. No automatic legacy-state migration is provided for changed code, predicate and transaction IDs.
- VM byte-operation migration implemented: `writeref` (0xad), `writepoint` (0xae), Slice-based `readpoint`, Builder `writezeros`, raw byte consumers and Builder transcript challenge outputs. `tread` is `m label b n -> m b'`; transcript labels/data accept zero-ref Cell/Slice/Builder payloads. Frame IDs/anchors produce Cells. Private annotations are checked against applicable public encodings; byte consumers never decode bearer Tokens. `loadref`/`cellinfo`/`cellhash`, bit operations, factual equality and raw hashing remain implemented. String and StringWitness are removed: `CellValue` holds `CellRef + Option<Arc<CellWitness>>` directly. Host `push_literal` preserves ordinary zero-ref payloads in source-byte APIs; graph/pruned literals require `to_cell`/`build_tx`, while `push_cell` carries native graph references including unloaded ones. Former String tag/type code 1 is reserved and rejected; Cell stays 13, without silently renumbering or importing old String state. MSM Boolean composition and pruning/virtualization VM instructions remain deferred.
- Constraint-register orthogonality implemented: `commit` accepts Point only, retaining its Pedersen opening; `amount` preserves quantity/flavor commitment annotations. External-only `expr` accepts Scalar or Variable. `alloc` now returns a copyable allocated Variable; `commit` returns a copyable committed Variable. Expressions and Dicts remain noncopyable, so reuse requires explicit Variable duplication and Expression materialization. Former `scalar` opcode 0x60 is reserved/unknown. `borrow` independently accepts public Scalars or committed Variables for quantity/flavor; mixed public/secret combinations produce WideToken/Token pairs. On that encrypted path, public quantity must fit `u64` and costs three R1CS items; secret quantity costs 67. Public flavor is any Scalar. Allocated Variables cannot become Token components without a public commitment. Tests cover all combinations, witness retention, allocation reuse, forbidden Expression copies and prover/verifier gas parity. `jumpif` deliberately accepts only public Scalars; Point validation deliberately matches CompressedRistretto, with curve checks deferred until decompression.
- `cellinfo` accepts Cell, Slice and Builder. Slice statistics describe unread bytes and remaining refs; Builder statistics describe its current contents. Both compute factual depth/level from cached child summaries, without hashing payloads or resolving child bodies, preserve the operand, and report pruned flag zero. Transient metadata inspection costs one gas per reference plus the instruction; Cells retain metered own-record lookup.
- Native executable graph operands implemented: `open`, `signcall`, `exec`, `setcode`, actor registry APIs and storage effects use Cells. `CellWitness::Script` retains native graph overlays. `signcall` binds the factual program CellID with its existing transcript domain/labels. `setcode` metered-loads the complete supplied ordinary DAG before persistence, retains explicit pruned terminals, and fails on missing ordinary bodies; stored effects/RPC CellEnvelope transport preserve references. Code-byte admission counts the root payload, while rent counts unique retained graph records. Actor destination/address byte formatting remains unchanged pending a separate redesign.
- Public MSM evaluation implemented: `evalpoint` (0x89) consumes the accumulator and computes an opaque Point immediately in external or actor execution. All points are checked, including zero-coefficient terms. Its complete gas price `884 + 160n` is exactly 4× MSM `verify` (`221 + 40n`); existing Scalar/Constraint/MSM verification prices are unchanged and documented by type. Realistic-scalar/point evaluation benchmarks include decompression and compression; the 4× premium is policy, not a hardware-measured ratio.
- Claimed-result commitment implemented: TxBody references a canonical pruned TxLog, committing precomputed effects independently of block position. The VM checks its hash(0) and depth(0); this root is the basis for future supplied-log path queries, without deriving result identity from block ordering.
